# Kaj je

Eksperiment dvojne reže je temelj kvantne mehanike. Delci (fotoni, elektroni) streljani skozi dve reži ustvarijo valovni vzorec — kot da gre delec skozi obe reži hkrati in interferira sam s seboj.

Ko eksperiment opazuješ (merilnik), se delec začne obnašati kot delec — gre skozi eno režo. Valovni vzorec izgine.

# Implikacija

Akt opazovanja/interakcije definira kaj se dogaja. Realnost se "rendira" ko jo opazujemo — pred tem obstaja kot neskončen potencial.

John Wheeler: **participatorno vesolje** — udeleženci so nujni da realnost ostane skupaj. Brez življenja bi vsak delec eksplodiral nazaj v neskončni potencial.

# Vzporednica s hindujsko filozofijo

- Brahman = neskončni potencial (nerendirana realnost)
- Atman (zavest) = opazovalec ki rendira
- Maya = renderirana realnost ki jo zaznamo
