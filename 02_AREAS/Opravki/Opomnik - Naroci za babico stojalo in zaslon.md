# Opomnik — Naroci za babico stojalo in zaslon

**Status:** čakanje na izvedbo
**Prioriteta:** visoka

## Kaj

Naročiti za babico:
1. **Stojalo** (za rastline, knjige, dekoracijo — kateri tip?)
2. **Zaslon** (za telefon, tablet, ali monitor?)

## Kje kupiti

- **IKEA** — stojala, policestavki
- **JYSK**  stojala in podstavki
- **Müller / DM** — zasloni za telefon/tablet
- **Amazon.de** — širši izbor
- **Bol.com** — dostava v EU

## Kriterije

### Stojalo
- Namen: rastline / knjige / dekoracija?
- Velikost: miza / tla / okenska police?
- Material: les / kov / plastika?

### Zaslon
- Za kaj: telefon / tablet / računalnik?
- Tip: zaščitni zaslon (proti praskam) / filter za svetlobo / monitor?
- Velikost/model naprave?

- [ ] Izmeriti potrebne dimenzije
- [ ] Poiskati ponudbe
- [ ] Naročiti in dostaviti
