# Opomnik — Zgruntaj kaj je z računalniki

**Status:** čakanje na izvedbo
**Prioriteta:** srednja

## Kaj

Preganje računalnikov — kaj deluje, kaj ne, kaj treba popraviti/nadgraditi.

## Računalniki za preveriti

### 1. Osebni računalnik (Windows/Linux)
- [ ] Deluje?
- [ ] OS posodobljen?
- [ ] Prostor na disku?
- [ ] Backup narejen?

### 2. Miza / delovna postaja
- [ ] Monitor deluje?
- [ ] Tipkovnica/miška OK?
- [ ] Povezave (WiFi/Ethernet)?

### 3. Strežnik / NAS (če obstaja)
- [ ] Vklopljen in dostopen?
- [ ] Diski zdravi?
- [ ] Backup teče?

### 4. Ostala naprave
- [ ] Tablet / telefon — OS posodobljen?
- [ ] Tiskalnik?
- [ ] Router / omrežje?

## Opomnik

- [ ] Pregledati vse računalnike
- [ ] Zapisati kaj treba popraviti
- [ ] Naročiti rezervne dele če rabni
