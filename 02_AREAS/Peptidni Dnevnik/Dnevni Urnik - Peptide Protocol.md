# Dnevni Urnik — Peptidni Protokol 2026

> **Kratek pravila:**
> - Tešče = vsaj 2–3 ure od zadnjega obroka + 45 min po injekciji
> - Injekcije: subkutano SC (trebuh/stegno, 45° kot)
> - Suplementi: lahko zajtrk/večerja skupaj z injekcijami (ne CJC+IPA!)
> - Vyvanse: 2–3 URI stran od Vitamin C

---

| Ura | Kaj | Zakaj? |

| **14:00** | Elektroliti + L-Carnitine | RT + Vyvanse = izguba elektrolitov (pogost stranski učinek). L-Carnitine = transport maščobnih kislin v mitohondrije za kurjenje maščob |
| **18:00** | Magnesium + Probiotiki | Magnesium = boljši globoki spanec + mišična regeneracija. Probiotiki = BPC-157 podpira črevesje, probiotiki ojačajo učinek |
| **22:00** | CJC+IPA (tešče 2–3 ure) | CJC+IPA sproža GH pulz. Če pojdeš zraven hrane → insulin naraste → GH sproščanje blokirano. Tešče = čisti GH pulz |
| **22:45** | Melatonin + spanje | Melatonin 0.5mg = nižja doza, ne duši naravni spanec. CJC+IPA že izboljšuje naravni GH pulz ponoči. Skupaj = **optimalen globoki spanec + GH sproščanje** |

## ⚠️ Ključna Pravila

1. **Nikoli ne jej 2–3 ure pred injekcijo** — insulin blokira CJC+IPA in RT učinek
2. **Počakaj 45–60 min po injekciji** — ne pojdi h kavi/obroku prej
3. **RT uvajaj počasi** — začni z 0.5mg, povečuj na 1mg, nato 2mg (prepreči navzeo in GI stranske učinke)
4. **Vyvanse + RT = dvojni apetit supresor** — nastavi alarm za obroke, minimum 150g proteina/dan
5. **Suplementi so OBVEZNI** — brez CoQ10/NMN dela SS-31 30% manj učinkovito
6. **Vitamin C POZNO** — ob 12:00, najmanj 2 uri od Vyvanse
7. **Protein minimum 150g/dan** — brez tega RT + CJC/Ipa razgrajujejo mišice namesto maščob
8. **Vadba 4–5×/teden** — brez vadbe stack deluje 50% manj učinkovito
