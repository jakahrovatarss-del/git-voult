## 📦 Trajanje & Kolčina

### GLOW50 (2 viale)
```
Doziranje: 750mcg/dan
Razpolovno: ~20mg/ml (pri rekonstituciji)
Poraba: ~3.75 enot/dan = 0.75mg = 750mcg
Cel količina: 100mg (2× 50mg)
Trajanje: 100mg / 0.75mg/dan = 133 dni (~19 tednov)

→ Zadostuje za cel cikel + 7 tednov rezerve!
```

### RT (4 viale)
```
Doziranje: 0.5mg (teden 1–2), 1mg (teden 3–4), 2mg (teden 5+)
Trajanje: 4 mg/teden (od teden 3)
Cel količina: 40mg (4× 10mg)
Trajanje: 40mg / 4mg/teden = 10 tednov

→ Če potrebuješ 12 tednov → naroči 2× dodatni = €50
```

### CJC+IPA (3 viale)
```
Doziranje: CJC 200mcg + IPA 300mcg, 4×/teden
Poraba CJC: 200mcg × 4 = 0.8mg/teden
Poraba IPA: 300mcg × 4 = 1.2mg/teden
Cel količina: 30mg CJC + 30mg IPA (3× 10+10mg viale)
Trajanje CJC: 30mg / 0.8mg/teden = 37.5 tednov ✅
Trajanje IPA: 30mg / 1.2mg/teden = 25 tednov ✅

→ Zadostuje za cel cikel + veliko rezerve!
```

### BAC10 (2 viale)
```
Poraba rekonstitucije:
- GLOW50: 2.5ml (prva viala) + 2.5ml (druga viala) = 5ml
- RT: 2ml × 4 = 8ml
- CJC+IPA: 2ml × 3 = 6ml
- SKUPAJ: 5 + 8 + 6 = 19ml

Dostop: 2 × 10ml = 20ml ✅ (zadošča!)

Če rabiš več → naroči še 1× dodatna = €5
```
