## Pravilo

Ko posodobiš katerokoli memory datoteko, **isti zapis posodobi tudi v**:
`/home/jaka/Zdaj Pa Zares Obsidian/memory/`

Obe lokaciji morata biti vedno sinhronizirani.

**Why:** Jaka bere memory datoteke direktno v Obsidianu — če posodobiš samo interno memory, Obsidian ostane zastarel.
**How to apply:** Po vsakem Write v interno memory mapo, naredi enak Write v `Zdaj Pa Zares Obsidian/memory/` (ista vsebina, ista datoteka).
