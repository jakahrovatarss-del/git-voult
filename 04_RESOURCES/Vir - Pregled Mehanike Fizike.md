## 1. Klasična Mehanika (00:00–02:33)

Klasična mehanika opisuje gibanje teles pri **vsakodnevnih hitrostih** (v ≪ c) in **makroskopskih masah**.

### Temeljni koncepti

| Količina | Simbol | Enota | Opis |
|----------|--------|-------|------|
| Položaj | $x$ | m | Lega telesa |
| Hitrost | $v = \dot{x}$ | m/s | Sprememba lege |
| Pospešek | $a = \ddot{x}$ | m/s² | Sprememba hitrosti |
| Sila | $F$ | N | Vzrok spremembe gibanja |
| Masa | $m$ | kg | Odpornost na spremembo gibanja |
| Gibalna količina | $p = mv$ | kg·m/s | |
| Navor | $\tau = r \times F$ | N·m | Vrtilni analog sile |
| Vztrajnostni moment | $I$ | kg·m² | Vrtilni analog mase |

### Newtonovi zakoni → za mehaniko KLJUČNO

$$\sum \vec{F} = 0 \quad \text{(statika)} \qquad \sum \vec{F} = m\vec{a} \quad \text{(dinamika)}$$

**1. zakon:** Telo miruje ali se giblje enakomerno, dokler nanje ne deluje sila.  
**2. zakon:** $F = ma$ — osnova celotne mehanike.  
**3. zakon:** $F_{12} = -F_{21}$ — akcija = reakcija (osnova FBD).

### Premo Enakomerno Gibanje (EPG)

$$v(t) = v_0 + at \qquad x(t) = x_0 + v_0t + \tfrac{1}{2}at^2 \qquad v^2 = v_0^2 + 2a\Delta x$$

### Rotacijsko gibanje

Analogije translacija ↔ rotacija:

| Translacija | Rotacija |
|-------------|----------|
| $x$ (lega) | $\theta$ (kot) |
| $v$ (hitrost) | $\omega$ (kotna hitrost) |
| $a$ (pospešek) | $\alpha$ (kotni pospešek) |
| $F = ma$ | $\tau = I\alpha$ |
| $p = mv$ | $L = I\omega$ |

### Trenje

$$F_s \leq \mu_s F_n \quad \text{(statično)} \qquad F_k = \mu_k F_n \quad \text{(kinetično)}$$

> Statično trenje > kinetično trenje → "harder to start than to keep moving"

## 2. Energija (02:33–04:40) — Ključno za Mehaniko

### Zakon ohranitve energije

$$E_{skupaj} = \text{konst.} \qquad \Delta KE + \Delta PE + W_{trenje} = 0$$

| Tip energije | Formula | Enota |
|--------------|---------|-------|
| Kinetična | $KE = \tfrac{1}{2}mv^2$ | J |
| Potencialna (gravitacijska) | $PE = mgh$ | J |
| Elastična | $PE_{el} = \tfrac{1}{2}kx^2$ | J |
| Dela sile | $W = F \cdot d \cdot \cos\theta$ | J |

### Moč

$$P = \frac{W}{t} = F \cdot v \qquad [P] = \text{W (watt)}$$

### Hooke-ov zakon (vzmet / elastičnost)

$$F = kx \qquad \text{(k = togostna konstanta [N/m])}$$

Energija deformacije: $U = \tfrac{1}{2}kx^2$ → direktno povezano z **upogibom** in **uklona**!

> Za mehaniko: elastična energija v upognjenem nosilcu je osnova analize napetosti.

## 3. Termodinamika (04:40–06:01) — manj relevantno za mehaniko

Osnove za splošno znanje:
- 0. zakon: Termično ravnovesje (temperatura se izenači)
- 1. zakon: $\Delta U = Q - W$ (ohranitev energije)
- 2. zakon: Entropija narašča → energija se razprši
- 3. zakon: Pri 0 K je entropija = 0

→ Za mehaniko relevantno pri: **termičnih napetostih** ($\sigma_{th} = E \cdot \alpha \cdot \Delta T$)

## 5. Relativnost (09:28–11:25) — mejni primer klasične mehanike

Klasična mehanika velja za $v \ll c$. Ko $v \to c$:
- Masa narašča: $m = m_0 / \sqrt{1-v^2/c^2}$
- Čas se upočasni

**Za mehaniko:** Klasična mehanika je **vedno dovolj** — nobena konstrukcija ne gre z relativistično hitrostjo.

## Pregled — Kaj mehanika (predmet) pokriva

```
Mehanika
├── Statika          → ΣF=0, ΣM=0, FBD, podpore, redukcija sil
├── Kinematika       → EPG, rotacija, trajektorije (brez sil)
├── Dinamika         → F=ma, energija, delo, moč
├── Trdnost          → napetosti, deformacije, upogib, uklon
└── Tehnično risanje → branje in ustvarjanje tehniških načrtov
```
